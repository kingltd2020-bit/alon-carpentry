# חיבור הטופס ל-n8n

מדריך לבנייה עצמית. אני לא בונה לך את ה-workflow —
אתה בונה, אני מסביר איפה כל נוד ולמה הוא שם.

---

## מה אנחנו פותרים

אלון כתב:

> *"אני לא רוצה לפספס פניות. היום הן מתערבבות לי בוואטסאפ ואני מגלה אותן אחרי שבוע."*

זו לא בקשה ל"טופס יצירת קשר". זו בקשה ל**תיבת דואר נכנס שלא מתערבבת**.
לכן ה-workflow חייב לעשות שני דברים, לא אחד:

1. **לרשום** את הפנייה במקום קבוע — שורה בגיליון. זה הזיכרון.
2. **להתריע** מיד — מייל או וואטסאפ. זו התשומת לב.

רק רישום → הוא לא יידע שהגיעה פנייה.
רק התראה → זה מתערבב לו שוב, בדיוק הבעיה המקורית.

## ה-workflow — חמישה נודים

```
[1 Webhook] → [2 Code: ולידציה] → [3 IF] → [4 Sheets: Append]
                                      ↓            ↓
                                   (דחייה)   [5 Gmail: התראה]
```

### 1 · Webhook

| הגדרה | ערך |
|---|---|
| HTTP Method | `POST` |
| Path | להשאיר את המזהה שנוצר |
| Respond | `Immediately` |

**למה Immediately:** הדף לא מחכה לתשובה מפורטת, רק ל-200.
מענה מיידי אומר שגם אם הגיליון איטי, הגולש רואה "קיבלתי" מיד.

אחרי השמירה יש שם שתי כתובות. ה-**Test** עובדת רק כשהחלון פתוח.
זו שגיאת המתחילים הקלאסית — לוקחים את Test, זה עובד בבדיקה,
ואז שקט. **קח את Production URL.**

**מה מגיע פנימה** — הדף שולח:

```json
{
  "name":    "ישראל ישראלי",
  "phone":   "052-1234567",
  "email":   "israel@example.com",
  "message": "שולחן אוכל 220x100",
  "company": "",
  "source":  "landing",
  "sentAt":  "2026-08-30T16:40:00.000Z"
}
```

הגוף יושב תחת `$json.body` (לא `$json`) כשה-Webhook מקבל JSON.
זה תופס אנשים כל הזמן — אם הביטויים יוצאים ריקים, זו כנראה הסיבה.

### 2 · Code — ולידציה

```js
const b = $input.first().json.body ?? $input.first().json;

const digits = String(b.phone ?? '').replace(/\D/g, '');
const email  = String(b.email ?? '').trim().toLowerCase().slice(0, 120);

return [{
  json: {
    ok:      !b.company
             && String(b.name ?? '').trim().length > 1
             && digits.length >= 9
             && /^[^\s@]+@[^\s@]+\.[^\s@]{2,}$/.test(email),
    name:    String(b.name ?? '').trim().slice(0, 80),
    phone:   digits,
    email,
    message: String(b.message ?? '').trim().slice(0, 1000),
    at:      new Date().toISOString()
  }
}];
```

שלוש שורות הגנה, וכל אחת קיימת מסיבה:

- `!b.company` — **מלכודת הספאם.** השדה מוסתר בדף, בן אדם לא רואה
  אותו. בוט ממלא כל שדה שהוא מוצא. מלא = בוט.
- `digits.length >= 9` — טלפון ישראלי תקין. `slice` — חוסם ניסיון
  להזריק טקסט ענק.
- **בדיקת המייל היא חוסמת, לא קוסמטית.** אם היא לא כאן, נוד
  מייל האישור ינסה לשלוח לכתובת שבורה, ייכשל, ויפיל את כל ההרצה —
  כולל את השורה בגיליון. הפנייה תיעלם בגלל תו חסר.
- הכל עובר `String(...)` לפני שנוגעים בו. לעולם לא לסמוך על
  מה שהגיע מהרשת.

### 3 · IF

תנאי בוליאני: `{{ $json.ok }}` הוא `true`.
ענף false — לא מחובר לכלום. הפנייה נבלעת בשקט, בלי להחזיר לבוט
מידע על מה נדחה.

### 4 · Google Sheets — Append Row

גיליון חדש, לשונית `Leads`, כותרות:

| at | name | phone | email | message | status |
|---|---|---|---|---|---|

`status` נשארת ריקה. זו העמודה שאלון ימלא ידנית —
`חזרתי` / `נסגר` / `לא רלוונטי`. **בלעדיה זה רק ערימה,
לא רשימת מעקב**, והכאב המקורי חוזר.

> ⚠️ Append ולא Update. אם תיקח נוד Update בטעות, הפנייה
> החדשה תדרוס את הקודמת ותגלה את זה מאוחר.

### 5 · Gmail — התראה

- **אל:** המייל של אלון
- **נושא:** `פנייה חדשה מהאתר — {{ $json.name }}`
- **גוף:** שם, טלפון, מה צריך, ולינק לגיליון

השם בנושא הוא לא קישוט. אלון רואה את זה בטלפון בהתראה,
ויודע אם זה דחוף בלי לפתוח.

## חיבור לדף

ב-[`../index.html`](../index.html), בבלוק ה-`<script>`:

```js
const WEBHOOK_URL = '';   // ← Production URL כאן
```

עד שזה ריק, הטופס עובד — הוא פשוט עובר ישר למסלול הוואטסאפ.

**כשמשנים: לעשות קומיט.** זה שינוי שמשפיע על התנהגות, וצריך
להיות ברור בהיסטוריה מתי המסלול הופעל.

## CORS — כאן זה ייתקע

הדף רץ בדומיין אחד, n8n בדומיין אחר. הדפדפן יחסום את הבקשה
אלא אם n8n עונה בכותרות הנכונות. **התסמין:** בקונסול מופיע
`blocked by CORS policy`, וב-n8n לא רואים שום בקשה.

בנוד ה-Webhook, תחת **Options → Response Headers**:

| Header | Value |
|---|---|
| `Access-Control-Allow-Origin` | הדומיין של הדף |
| `Access-Control-Allow-Headers` | `Content-Type` |
| `Access-Control-Allow-Methods` | `POST, OPTIONS` |

**לא לשים `*`.** זה פותח את ה-webhook לכל אתר באינטרנט,
וכל בוט יוכל להזריק שורות לגיליון של אלון.

הדפדפן גם שולח בקשת `OPTIONS` מקדימה. אם n8n לא עונה לה,
ה-POST לא ייצא לדרך — צריך שה-webhook יקבל גם `OPTIONS`.

## בדיקה לפני שסוגרים

| # | בדיקה | מה צריך לקרות |
|---|---|---|
| 1 | טופס תקין מהטלפון | שורה בגיליון **וגם** מייל |
| 2 | למלא את השדה `company` בדפדפן ולשלוח | כלום. בשקט |
| 3 | טלפון של 3 ספרות | נדחה |
| 4 | לכבות את הרשת ולשלוח | מופיע קישור וואטסאפ עם הפרטים בפנים |
| 5 | לשלוח פעמיים | שתי שורות, לא אחת שנדרסה |

בדיקה 4 היא הלב. היא מוודאת שגם כשהכל נופל — **הפנייה לא הולכת לאיבוד.**
זו הדרישה שאלון ניסח, וזו הבדיקה היחידה שאסור לוותר עליה.
