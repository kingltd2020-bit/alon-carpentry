## מה נעשה ללוגו

הקובץ המקורי הגיע עם **רקע לא שקוף** — דפוס שחמט צרוב בפיקסלים (גווני 244–254),
לא ערוץ אלפא. הנחתו כמו שהוא על הדף הייתה יוצרת ריבוע אפור סביבו.

1. **הערכת רקע** מחציון פיקסלי המסגרת → `(250,250,250)`
2. **אלפא ממרחק צבע** מהרקע: מתחת ל-18 שקוף, מעל 50 אטום, ביניהם מדורג
3. **ביטול המיזוג בקצוות** — `C = (observed − (1−α)·bg) / α`, מסיר הילה לבנה
4. **חיתוך צמוד** לתיבת התוכן
5. **הקטנה ל-480px** — כפול תצוגת 240px למסכי Retina
6. **קוונטיזציה ל-64 צבעים** → 8.9KB

**למה PNG ולא WebP:** נוסה WebP באיכות 85 והגיע ל-20.9KB —
**גדול פי 2.3 מה-PNG**. הלוגו הוא בעיקרו שני צבעים שטוחים, מה
ש-WebP הלוסי לא מרוויח ממנו אבל פלטת 64 צבעים כן. נבדק, לא הונח.
