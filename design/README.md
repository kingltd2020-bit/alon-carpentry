# design/

מקורות לוחות העיצוב (Claude Design). **אלה קבצי מקור, לא הדף החי** —
הדף החי הוא `../index.html`.

| קובץ | מה זה |
|---|---|
| `Main.dc.html` | הדף המלא ברוחב 390px — הכיוון שנבחר |
| `Tokens.dc.html` | מערכת העיצוב: צבע, טיפוגרפיה, כללים |
| `DirectionB.dc.html` | חלופה שנפסלה — "לוח סרטוט" |
| `DirectionC.dc.html` | חלופה שנפסלה — "עץ אגוז כהה" |
| `canvas.json` | פריסת הלוחות והפתקים על הקנבס |
| `logo.png` | העתק מ-`../assets/`. הכלי טוען תמונות מתיקיית העבודה שלו |

## הכיוון שנבחר — "סדנה שקטה"

רקע נייר חם · קו שיער 1px במקום צל · טיפוגרפיה גדולה · צבע חם אחד.

**הנימוק:** אלון כתב *"אל תכתבו שאני הכי טוב בארץ, אני לא אוהב את זה."*
עיצוב שקט אומר את זה בלי לכתוב את זה. הדף לא צועק — כמו המייל שלו.

## אין webfont

לא Google Fonts ולא פונט מקומי. פונט מערכת בלבד.
**הסיבה:** הדרישה המפורשת היא פתיחה מהירה ברשת חלשה, וכל פונט חיצוני
מוסיף רכיבת רשת לדומיין נוסף לפני שהטקסט מצויר.
האופי מגיע מהסקאלה, מהמרווחים ומהקווים.

## לעדכן את הקנבס

עורכים את קובצי ה-`.dc.html` כאן, ואז מרכיבים מחדש ומעדכנים את אותו קישור.
הקובץ המורכב עצמו (~2MB) הוא תוצר זמני ואינו נשמר בריפו.
