## הבאג שהבדיקה תפסה

מלכודת הספאם הוסתרה ב-`left:-9999px` — הטריק הסטנדרטי.
**ב-RTL זה נשבר.** כיוון הגלילה הפוך, ואלמנט שמוזז 9999px שמאלה
יוצר גלילה אופקית בכל הדף:

```
FAIL no-h-overflow [10319>320]
```

10,319 פיקסל רוחב גלילה במסך של 320. בטלפון זה מרגיש כמו דף שבור.
התיקון: `clip-path: inset(50%)` — מסתיר בלי לייצר overflow.

זה בדיוק סוג הדבר שלא רואים בעין ורואים במדידה.

## איך מריצים

צריך כרום. הסקריפט נדחף לתוך עותק של הדף, והתוצאות יוצאות ב-`<title>`:

```bash
cat index.html > t.html
echo '<script>' >> t.html && cat tools/check.js >> t.html && echo '</script>' >> t.html
chrome --headless --disable-gpu --virtual-time-budget=8000 --window-size=390,900 \
       --dump-dom "file:///$PWD/t.html" | grep -o '<title>RESULTS[^<]*'
rm t.html
```

**הערה:** `--screenshot` של chrome-headless-shell מחזיר במכונה הזו תמונה
ריקה בלי טקסט. המדידות דרך `--dump-dom` עובדות, ולצורך אימות פריסה הן
ממילא אמינות יותר מצילום מסך.
