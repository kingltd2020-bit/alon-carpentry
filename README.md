# אלון — נגרות בהתאמה אישית

דף נחיתה לנגר עצמאי מפרדס חנה. תרגיל שיעור 7, קורס AI DEV.

**המטרה שהלקוח הגדיר:** קישור אחד שהוא מעביר לאנשים, שנפתח מהר בטלפון
ברשת חלשה, ושפניות ממנו מגיעות אליו מסודרות במקום להתערבב בוואטסאפ.

---

## חוק התוכן

> **[`docs/business-facts.md`](docs/business-facts.md) הוא מקור האמת היחיד.**

כל מילה בדף חייבת להיות שם. הלקוח כתב במפורש:
*"אין לי פרסים ואין לי המלצות כתובות, אז אל תמציאו."*

לפני שינוי תוכן — לקרוא את הקובץ הזה. לפני הוספת טענה — למצוא אותה שם.
אין שם? לא נכנס לדף.

---

## מבנה

```
alon-carpentry/
├─ index.html              הדף. קובץ אחד
├─ assets/                 נכסים מעובדים ומוכנים לפריסה
├─ docs/
│  └─ business-facts.md    ← מקור האמת. לקרוא לפני כל שינוי תוכן
└─ _source/                מקורות כבדים. לא בגיט (ראה .gitignore)
```

## הרצה

אין תלויות, אין שלב build, אין התקנות. פותחים את `index.html` בדפדפן.

## החלטות

| נושא | החלטה | נימוק |
|---|---|---|
| ללא framework | HTML + CSS בלבד | הדרישה היא מהירות בטלפון ברשת חלשה. framework הוא משקל בלי תמורה לדף אחד |
| ללא Google Fonts | פונט מערכת | חוסך רכיבת רשת לדומיין חיצוני. בעברית ההבדל מורגש ברשת איטית |
| התמונה | אזור אחד | ללקוח אין צילומים. עדיף מקום שמור אחד מאשר גלריה של מציאות מומצאת |
| ללא JS חיצוני | vanilla, מינימלי | פחות מה שיכול להישבר וכלום להוריד |
