# אלון — נגרות בהתאמה אישית

דף נחיתה לנגר עצמאי מפרדס חנה. תרגיל שיעור 7, קורס AI DEV.

**מה הלקוח ביקש:** קישור אחד שהוא מעביר לאנשים, שנפתח מהר בטלפון
ברשת חלשה, ושפניות ממנו מגיעות אליו מסודרות במקום להתערבב בוואטסאפ.

## חוק התוכן

> **[`docs/business-facts.md`](docs/business-facts.md) הוא מקור האמת היחיד.**

כל מילה בדף חייבת להיות שם. הלקוח כתב במפורש:
*"אין לי פרסים ואין לי המלצות כתובות, אז אל תמציאו."*

לפני שינוי תוכן — לקרוא את הקובץ. לפני הוספת טענה — למצוא אותה שם.
אין שם? לא נכנס לדף. הבדיקה מספר 13 ב-`tools/check.js` סורקת את הדף
מול רשימת האיסורים ותיפול אם שפה שיווקית תתגנב פנימה.

## החלטות

| נושא | החלטה | נימוק |
|---|---|---|
| ללא framework | HTML + CSS בלבד | דף אחד. framework הוא משקל בלי תמורה |
| ללא Google Fonts | פונט מערכת | פונט חיצוני = רכיבת רשת לדומיין נוסף לפני שהטקסט מצויר. האופי מגיע מהסקאלה והמרווחים |
| CSS משובץ ולא `style.css` | inline | קובץ נפרד הוא בקשת רשת שחוסמת ציור. ב-4KB השיבוץ מנצח קאשינג — רוב הכניסות הן ראשונות, מקישור בוואטסאפ |
| לוגו PNG ולא WebP | PNG-8, 64 צבעים | נמדד: WebP q85 הגיע ל-20.9KB, PNG מקוונטז ל-8.9KB. הלוגו שטוח מדי מכדי ש-WebP ירוויח |
| אזור תמונה אחד | placeholder ביחס 3:2 | ללקוח אין צילומים והוא ביקש לא להמציא. `aspect-ratio` מקבע את הגובה כך שאין קפיצה כשהתמונה תיכנס |
| טופס עם מסלול גיבוי | fetch → וואטסאפ | הכאב שלו הוא פניות שהולכות לאיבוד. כשה-webhook נכשל הדף לא מוחק את מה שנכתב — הוא בונה קישור וואטסאפ עם הפרטים |
